## 💻 Tech Stack
- **Python** – Core programming language  
- **Streamlit** – Web interface for real-time interaction  
- **OpenCV** – Face detection, image processing  
- **MediaPipe** – Face landmark detection  
- **NumPy / Pandas** – Data handling and visualization  
- **Matplotlib** – Dataset and statistics visualization  
- **Hashlib** – Secure password hashing for admin login  
- **CSV / JSON** – User dataset storage
